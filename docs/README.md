# Documentation

- `implementation-plan.md` — the consolidated architecture/implementation plan (historical snapshot; the living version is the linked Claude doc inside it). Update the snapshot when the plan changes meaningfully; don't treat it as the only source of truth.
- `adr/` — Architecture Decision Records. One dated markdown file per significant decision (e.g. "why SQLite over embedded Postgres"). See `adr/README.md`.
- `product/` — end-user and operator-facing documentation (how to use the app, how a group's treasurer sets things up, release notes for non-engineers). Empty until there's a product to document.

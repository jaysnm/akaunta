# Architecture Decision Records

One file per significant, hard-to-reverse decision: `NNNN-short-title.md`, numbered sequentially.

Template:

```markdown
# NNNN: Title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by NNNN

## Context

What problem forced a choice.

## Decision

What was chosen.

## Consequences

What this makes easier, harder, or forecloses.
```
